## نکته امنیتی مهم
این نسخه برای GitHub Pages یک نسخه فرانت‌اند/دمو است. رمز داخل JavaScript امنیت واقعی ایجاد نمی‌کند و localStorage دیتابیس واقعی نیست.
برای نسخه نهایی واقعی باید احراز هویت مالک + دیتابیس + API امن اضافه شود و ارسال خودکار SMS از طریق سرویس SMS انجام شود.
