AMIRY Modern Website
======================
فایل‌ها:
- index.html
- style.css
- script.js

ویژگی‌ها:
- موبایل: ۲ استایل در هر ردیف
- کامپیوتر: ۴ استایل در هر ردیف
- منوی سه‌خطی بازشونده
- فارسی / پشتو / انگلیسی
- نمایش قیمت واقعی هر استایل، محدود به 50 تا 500 افغانی
- جستجو و فیلتر
- جزئیات استایل
- لایک و کامنت
- فرم نوبت با نام، تخلص، شماره، تاریخ، ساعت و استایل
- پنل مدیریت برای ویرایش/حذف/قیمت/عکس/پس‌زمینه
- تعداد نوبت‌ها از داده واقعی ثبت‌شده خوانده می‌شود و اگر نوبتی نباشد 0 نشان می‌دهد.

نکته مهم امنیتی:
این نسخه برای GitHub Pages است و اطلاعات را در localStorage مرورگر نگه می‌دارد. PIN داخل JavaScript امنیت واقعی ایجاد نمی‌کند. برای اینکه فقط مالک واقعاً بتواند پنل را ببیند و تغییرات/نوبت‌ها برای همه کاربران یکسان و دائمی باشد، باید یک backend/database و احراز هویت واقعی اضافه شود. همچنین ارسال SMS واقعی به +93773269043 و 0748603450 نیاز به سرویس پیامک و backend دارد.
